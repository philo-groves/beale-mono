# Plugin vendor marks

The Meta mark comes from [Tabler Icons](https://github.com/tabler/tabler-icons/blob/main/icons/outline/brand-meta.svg), licensed under the MIT license in [LICENSE](LICENSE). Its SVG paths carry explicit stroke attributes so Rune renders the original outline.

The Apple and Windows plugin marks reuse the MIT-licensed [Bootstrap Icons assets](../fleet-logos/SOURCES.md) used by Fleet.
