# Changelog

## Unreleased

### Beale

#### Added

- Beale iOS active-session composers now expose the shared app-server Stop action in the Send button position, including while a shell or computer-use approval is pending; typing a steering message changes the same control back to Send.
- Beale iOS session headers now use an icon-only status circle that opens Desktop-style Active and Completed subagent rows with status, latest message, channel, model, and activity age; selecting a row opens that subagent's filtered commentary stream.
- Beale iOS New Research now shows canonical workspace suggestions that fill the request, offers a checked Add Context launch option that expands the goal with bounded campaign-aware host context, and can launch it as a persistent Goal whose original objective survives context expansion.
- Beale iOS New Research now configures the Lead provider/model, zero or more collaborator subagent models and reasoning levels, Simple or Advanced subagent mode, and Manual Approval, Auto Review, or Danger shell safety before launch.
- Beale iOS workspace views can now start a new research session from a multiline request, using app-server-owned provider and safety policy before opening the live session commentary.
- Desktop Lag Profiling can now be enabled from General settings and captures bounded renderer long tasks, event-loop delay, dropped-frame gaps, React commit cost, session projection work, input latency, and a correlated timing timeline. Its profiling overview ranks likely lag causes and writes the complete structured session to temporary JSONL.
- Repository Resources now open an explicit Deep or Shallow clone dialog. Deep clones are the default for full-history research, while depth-one shallow clones remain available for prohibitively large repositories.
- Desktop workspace Campaign views now include a four-lane Board beside Trail for Refuted, Observed, Reproduced, and Verified findings. Equal-width, independently scrolling swimlanes show their filtered finding counts, reuse Priority Claim cards with compact rating metadata and filtering that prefer the latest CVSS qualitative severity, explicitly exclude proposed Leads, and support inline Class and Rating filters; Trail and Board headings identify their active subview.
- Active Desktop session titles in the app header now open a wide squircle Session Overview dialog with the session's Campaign Trail activity projection.
- Desktop workspace Campaign views now include a centered Claims sub-view after Trail, with separate expandable Findings and Leads lists that initially show four items and open canonical claim details. The Memories label is now consistently plural, and Memories and Runbooks headings align with Trail and Claims.
- Desktop Quick Chat opens compact, collapsible, closeable chat cards from the left sidenav and stacks concurrent chats leftward from the bottom-right corner. Quick chats run in an unlisted internal workspace with authenticated introspection tools for querying and editing registered Beale workspaces.
- Desktop Agent Settings now includes an Archive view for archived Sessions and Channels. Hover archive controls replace sidebar activity ages, require confirmation, preserve durable research data, and allow both item types to be restored.
- Desktop Agent Settings Archive now lists closed Quick Chats and can resume their original Honeycrisp session and transcript in a reopened Quick Chat card.
- Research claims now carry an explicitly untrusted Informational, Low, Medium, High, or Critical rating in Desktop and iOS claim views. Claim notifications use that label in their title while lifecycle state still independently controls whether an alert is emitted.
- Channels now persist a shared resource index for files, runbooks, and memories. Agents can publish and inherit typed resource references across sessions, while the channel sidebar shows resource counts and transcript attachments open their shared-resource details. The left-sidenav channel list shows four entries by default and reveals additional channels through an animated Show more/Show less control.
- Added workspace-lifetime research Channels with a Workspaces/Channels left-sidenav switcher, durable transcripts, membership, human posting, explicit deletion, and a right summary sidenav whose subagent rows open the originating session's full subagent commentary view.
- The left-sidenav workspace add control now offers Create Workspace and Import Workspace; import selects an existing directory, opens its persisted Beale state, and registers it in the workspace catalog.
- Campaign claim details now show evidence-backed reachability, operator-audited risk treatment, versioned CVSS vectors and assessed scores, affected assets and versions, and external security references. The app-server contract timestamp advances with a path-free security-tracking projection and capability, and the Honeycrisp runtime contract advances to v6 with finding schema v3 and memory-summary schema v5.
- Added a Google OSS VRP Research Kit with the official published OT0 and OT1 repository catalog, preserved repository-tier metadata, Google Bug Hunters OSS rules and report requirements, bundled refresh support, and Googlesource repository materialization.
- Added a canonical research-claim ledger that preserves one stable ID as a proposed Lead becomes an evidence-backed Finding. Profiles define research-agnostic classifications, including isolated and composite security findings plus mathematical conjectures, theorems, and counterexamples; evidence-gated promotion, reproduction, independent verification, reporting, disclosure, staleness, and component relationships remain append-audited.
- Desktop and Beale iOS canonical workspace views now transport and distinguish reusable knowledge, Leads, and Findings. Campaign projection consumes those same claim identities, and the app-server/WebSocket contract advances to v5 with claim-ledger capabilities and path-free v2 notification/catalog schemas.
- Desktop Appearance settings now persist Solid, Semi-Transparent, Gradient, and Blur background preferences, with Gradient selected for new installations and Solid preserving the original window surface. Semi-Transparent provides a persisted 10%–90% transparency selector defaulting to 50%, Gradient blends the active Session Heat color into a full-width theme-specific wash, and Blur requests the native macOS or Windows window material where supported.
- Beale iOS workspace views now link their live memory count to a path-free, text- and type-filterable memory catalog, and active session inputs now switch inline to pending shell or computer-use human approval actions.
- Workspace memory now uses one canonical Enabled backend with knowledge, claim-ledger, and campaign-track behavior, plus Disabled. Legacy Honeycrisp v1, v2 Shadow, and v2 selections normalize to Enabled without deleting stored data; legacy claim-shaped memory and finding rows migrate idempotently into the stable ledger and remain available for audit.
- Workspace Settings persists memory as Enabled or Disabled per workspace. Disabled removes knowledge recall, claim, campaign, notification, and Dreaming behavior from new sessions without deleting stored state; registry migration 11 records the selection.
- Beale iOS now uses the Desktop Beale artwork as its home-screen icon and adds a Settings destination with horizontal General and Connections views. Notification preferences live under General, while launch and Settings present saved app servers as a selectable connection list with a dedicated Add Connection flow.
- Desktop Remote settings can now detect the host's Tailscale MagicDNS name, configure a dedicated HTTPS Tailscale Serve listener for Beale iOS, persist the connection, and restart the loopback-only app-server with separate local and advertised endpoints.
- The Windows and macOS app-server tray menu can now show a versioned iOS connection QR code, and Beale iOS can scan it with the camera, validate its HTTPS origin, provision the operator token into Keychain, and connect immediately.
- Desktop and Beale iOS can now attach to and steer the same active Honeycrisp session concurrently. The app-server fans one hosted worker event stream across independently authenticated clients, retains runs when one device disconnects, and exposes operator-authenticated attachment-token minting for mobile joins.
- Beale iOS can now opt into local research-attention alerts. Product-level claim lifecycle and staleness determine urgency independently of research-profile semantics, with confirmed sink-role flow endpoints as the bounded knowledge signal. Active session views check immediately, iOS schedules best-effort background refreshes, and the app-server exposes a path-free canonical feed without memory bodies, evidence, attributes, or host storage metadata.
- Beale iOS session rows now open prompt and transcript views; active views follow the canonical cursor-based transcript feed for new commentary and final responses.
- Beale iOS now opens its Workspaces catalog after connecting, expands each workspace from its three newest named sessions to its full bounded catalog, and uses the leading Workspaces menu action to return from nested workspace or session views.
- Added a basic native Beale iOS client under `apps/ios` with HTTPS Tailscale Serve provisioning, Keychain-backed operator authentication, strict app-server compatibility checks, and authenticated workspace and live-session catalogs.
- Workspace Campaign view now visualizes authorized assets, durable memory, canonical findings, runbooks, and reports; ranks uncovered assets, unsupported claims, lifecycle gaps, staleness, and contradictions; and opens the highest-value gap as a prefilled research run.
- Runbook views now support inclusive start/end cell selection in addition to whole-run and single-cell execution, allowing a repaired late failure to continue without replaying successful prefix cells.
- Honeycrisp-backed findings now expose an evidence-gated lifecycle from hypothesis through observation, reproduction, independent verification, report readiness, disclosure, rejection, and source/environment staleness.
- Added an authenticated app-server host control plane for Desktop, Beale-iOS, and future clients to list path-free workspace summaries and read bounded canonical memory, sessions, updates, events, collaboration, and capture metadata through Honeycrisp's versioned protocol.
- Specialized workspaces now expose an active-kit-only dashboard view with a shared refresh form. HackerOne re-imports current program resources, rules, and guidance; Apple and Google OSS refresh selected repository metadata plus bundled rules and guidance; MSRC refreshes bundled rules and guidance while preserving manual resources and repository checkout metadata.
- Research Kits formalize General, HackerOne, Apple Security Bounty, Google OSS VRP, and MSRC workspace creation behind typed resource, scope, rule, and repository-catalog acquisition metadata. The selected kit is immutable workspace metadata, survives registry removal and re-import, and appears read-only beneath Research Profile in Workspace Settings; registry migration 10 records it for known workspaces.
